# 🛍️ فروشگاه اکانت ویژه

یک وبسایت فروش اکانت با قابلیت ارسال خودکار اطلاعات به تلگرام

## 📁 فایل‌های پروژه

- `index.html` - صفحه ثبت‌نام
- `products.html` - صفحه محصولات  
- `about.html` - صفحه درباره ما و تماس
- `bot.py` - ربات تلگرام
- `README.md` - این فایل راهنما

## 🚀 راه‌اندازی سریع

### ۱. آپلود روی GitHub Pages
1. یک ریپازیتوری جدید در GitHub ایجاد کنید
2. تمام فایل‌های HTML را آپلود کنید
3. به Settings > Pages رفته و گزینه GitHub Pages را فعال کنید
